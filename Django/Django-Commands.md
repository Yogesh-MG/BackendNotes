#### Basic Commands of Django
	
	To find version                           ``$django --verion
	To start an project                       ``$django-admin startproject <name> 
    To start an app                           ``$django-admin startapp <appname> 
	To run a server                           ``$py manage.py runserver
	To set the migration                      ``$py manage.py makemigrations
	To implement the migration                ``$py manage.py migrate
	To enter the shell                        ``$py manage.py shell
	To collect static files                   ``$py manage.py collectstatic
